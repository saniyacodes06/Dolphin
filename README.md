# 🐬 Dolphin Explorer

An interactive and visually immersive dolphin information website built using **Next.js, TypeScript, Tailwind CSS, shadcn/ui, and GSAP**.

This project was created as part of a beginner-friendly exploration of **AI-assisted web development**, where modern development tools, prompt engineering, and vibe coding techniques were used to transform ideas into a fully functional website.

---

## 🌊 Project Overview

Dolphin Explorer is an educational website designed to help users learn about dolphins through engaging visuals, smooth animations, and structured storytelling.

The website combines modern frontend technologies with AI-assisted development workflows to demonstrate how beginners can rapidly build polished web experiences using natural language prompts and iterative design.

---

---

## 🤖 AI-Assisted Development Approach

This project was intentionally developed using a **Vibe Coding** workflow.

Instead of manually designing every component from scratch, AI tools were used to:

* Generate UI ideas
* Create design systems
* Structure page layouts
* Suggest animation flows
* Improve responsiveness
* Refine content hierarchy
* Accelerate frontend development

The goal was not simply to build a website, but to learn how developers can collaborate effectively with AI tools through well-crafted prompts.

---

## 💡 What is Vibe Coding?

Vibe Coding is an iterative development process where developers:

1. Define requirements in natural language.
2. Use AI tools to generate implementation ideas.
3. Review and refine generated outputs.
4. Integrate, customize, and improve the code.
5. Continuously iterate until the desired experience is achieved.

This project serves as a practical example of that workflow.
